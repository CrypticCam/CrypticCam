# 💊 Eczane Otomasyonu

C dili ile geliştirilmiş konsol tabanlı eczane yönetim sistemi.

## 📌 Özellikler

- İlaç kayıt ekleme
- İlaç satışı ve hasta takibi
- Kayıt güncelleme
- İlaç listeleme
- Sistem sıfırlama

## 🛠️ Kullanılan Teknolojiler

- C Programlama Dili
- Dinamik bellek yönetimi (`malloc`, `realloc`, `free`)
- Struct veri yapıları
- Pointer aritmetiği
